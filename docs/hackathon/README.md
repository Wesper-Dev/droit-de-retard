# Archive du hackathon — juillet 2026

**Ces documents sont gelés et ne sont plus maintenus.**

Ils datent du Gemma 4 Hackathon (Track 02 — Autonomous Agents) et décrivent
l'état du projet à ce moment-là. Ils sont conservés pour la provenance : ils
montrent d'où vient le projet et comment il a été construit sous contrainte de
temps.

**Ne t'y fie pas pour l'état actuel.** Les chiffres qu'ils contiennent — nombre
de tests, port d'écoute, avancement, limites — étaient exacts en juillet 2026 et
ne le sont plus. Par exemple, ces documents annoncent 32 tests ; le dépôt en
compte aujourd'hui plus de cent.
